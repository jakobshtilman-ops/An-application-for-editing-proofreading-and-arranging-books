# מערכת קלדנות וניהול פרודוקטיביות (Typing Productivity Hub) ⏳📖

אפליקציית פרודוקטיביות, שעון עבודה מתקדם, ניהול זמנים, ארכיון ספרים וחישוב שכר לעורכי ספרים וקלדנים תורניים וכלליים – **עם תמיכה מלאה באופליין (100% Offline PWA)** ומוכנה להפעלה והפצה ישירה ב-**GitHub Pages**.

---

## 🌟 תכונות עיקריות (Key Features)

1. **עבודה באופליין מלא (100% Offline PWA)**:
   - כל הנתונים, הטיימרים, הסשנים וההיסטוריה נשמרים מקומית על גבי המכשיר/הדפדפן (`localStorage` עם גיבוי זיכרון חסין חסימות).
   - שירות Service Worker מתקדם מבוסס Workbox המטמיר את כל הקבצים (HTML, CSS, JS, גרפים, סמלים, פונטים) כך שהאפליקציה עובדת ברכבת, בטיסה או במקומות ללא אינטרנט.
   - התקנה כאפליקציה שולחנית (Windows / Mac / Linux) או בסמארטפון (Android / iOS) ישירות מתוך הדפדפן.

2. **שעון עבודה וטיימר רציף עם חלון צף (Picture-in-Picture)**:
   - שעון עבודה מדויק עד רמת מאיות השנייה.
   - **חלון צף תמידי (Always on Top)**: ניתן לשחק את הטיימר כחלון צף שיישאר מעל תוכנות העריכה שלך (כגון Microsoft Word, תג, Adobe InDesign).
   - סימולטור ספירת תווים והדבקת לוח עם אפשרות לדריסה ידנית מתוך ספירת התווים המדויקת של וורד.
   - **אזור פתקים והערות מהירות (Quick Notes)**: שמירת הערות זמניות, מראי מקומות, תזכורות והוראות עריכה לספר הנוכחי הנשמרות אוטומטית מקומית, כולל ספירת מילים/תווים, הוספת חותמת זמן והעתקה מהירה.

3. **מצבי עבודה מותאמים**:
   - **עבודה רגילה**: תמחור לפי יעד תווים לשעה וסך תווים (למשל 4,500 תווים לשעה).
   - **עבודה לפי שעות**: הגדרת תעריף שעתי מותאם אישית (לדוגמה ₪45 לשעה) וחישוב רווח בזמן אמת לפי שעות בפועל.

4. **ממשק דו-לשוני (עברית / אידיש)**:
   - תמיכה מלאה ב-RTL בעברית ובאידיש בלחיצת כפתור אחת.

5. **ארכיון ספרים ולוג סשנים שקט**:
   - שמירה וארכוב של כל ספר שהסתיים עם שעות עבודה (בפורמט HH:MM:SS), תווים, קצב, אחוז התאמה ליעד ותשלום מצטבר.
   - לוג סשנים שקט המתעד אוטומטית כל הפעלה ועצירה של השעון.

6. **לוח בקרה מתקדם (Dashboard) וגרף כפול-ציר**:
   - גרף מגמות 15 חודשים משולב (הכנסה, שעות עבודה ואחוז עמידה ביעד מו"ל).
   - מערכת התראה מוקדמת לשחיקה (Burnout System).
   - מדד רעננות לפי ימי השבוע ושעות הזהב של היממה.
   - מחשבון תמחור מטרות חודשי דינמי (סליידר יעדי הכנסה).

7. **מחשבוני עזר מהירים**:
   - מחשבון אריתמטי בסיסי מהיר.
   - מחשבון ממוצעי הספקים.
   - ממיר שעות, דקות ושניות דו-כיווני.

8. **גיבוי, ייבוא וייצוא מלאים (JSON)**:
   - כפתור שמירה מאובטחת.
   - ייצוא קובץ גיבוי של כל ההיסטוריה וההגדרות לקובץ JSON במחשב.
   - ייבוא קובץ גיבוי לשחזור או העברה בין מחשבים.

9. **שמירה ישירה לקובץ בדיסק המחשב (File System Access API)**:
   - חיבור וקישור קובץ JSON ישירות בדיסק המחשב (שולחן העבודה, מסמכים או כל תיקייה).
   - לחיצה על שמירה כותבת ומעדכנת ישירות את הקובץ במחשב ללא תלות בדפדפן!

10. **מודול מעקב יעדים מתקדם לפי טווחי זמן (שעות, ימים, שבועות, חודשים)**:
   - הגדרת יעדי תווים, שעות עבודה או הכנסה כספית ב-₪.
   - התאמה לטווח זמן: לפי שעות / סשן, לפי ימים (יומי), לפי שבועות (שבועי) ולפי חודשים (חודשי).
   - חישוב קצב נדרש בזמן אמת (Pace Calculation) לעמידה ביעד לפני הדדליין.

## 🚀 הרצה מקומית במחשב (Local Development)

```bash
# 1. התקנת התלויות
npm install

# 2. הרצת שרת הפיתוח המקומי
npm run dev
```

פתח את הדפדפן בכתובת `http://localhost:3000` (או הכתובת המוצגת בטרמינל).

---

## 📦 בנייה לפרודקשן (Production Build)

```bash
npm run build
```

התוצרים ייבנו לתוך תיקיית `dist/`, כולל ה-Service Worker, קובץ ה-Manifest וכל הנכסים הדרושים לאופליין.

## 🌐 העלאה ל-GitHub והפצה חינמית ב-GitHub Pages

1. **יצירת Repository ב-GitHub**:
   - צור ריפוזיטורי חדש ב-GitHub (ציבורי או פרטי).

2. **דחיפת הקוד**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - Typing Productivity Hub PWA"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
   git push -u origin main
   ```

3. **הפעלת GitHub Pages**:
   - היכנס להגדרות הריפוזיטורי ב-GitHub: **Settings** -> **Pages**.
   - תחת **Build and deployment** -> **Source**, בחר ב-**GitHub Actions**.
   - הקובץ `.github/workflows/deploy.yml` שנמצא בפרויקט יבנה ויפרסם את האפליקציה אוטומטית בכל Push!
   - תוך דקות ספורות האפליקציה תהיה באוויר עם כתובת אינטרנט ייעודית, תעודת SSL ו-PWA עם אופליין מלא.

## 📱 התקנה כאפליקציה (PWA Installation)

- **מחשב (Chrome / Edge / Brave)**: לחץ על כפתור ״התקנת אפליקציה למחשב״ בסרגל העליון, או על סמל ההתקנה בשורת הכתובת.
- **אייפון / אייפד (Safari)**: לחץ על ״שיתוף״ (Share) ובחר ״הוסף למסך הבית״ (Add to Home Screen).
- **אנדרואיד (Chrome)**: לחץ על התקן בסרגל העליון או בתפריט שלוש הנקודות ״הוסף למסך הבית״.
